# Manufacturing-OEE-Project
Manufacturing data analysis project using Power BI, Excel, and Python, including EDA, OEE dashboards, machine performance, downtime, and quality analysis.

## About the Project
This project focuses on analysing manufacturing data using Power BI, Excel and Python. It helps understand machine performance, production efficiency, downtime and product quality.

## Tools Used
- Power BI
- Microsoft Excel
- Python
- Pandas
- Matplotlib
- Seaborn

## Project Contents
1. **Power BI Dashboard** – Interactive dashboard with three pages.
2. **Excel Analysis** – Manufacturing data analysis.
3. **EDA** – Exploratory Data Analysis using Python.
4. **Documentation** – Project details and insights.

## Dashboard Pages
- OEE Executive Overview
- Machine Performance
- Downtime & Quality Analysis

## Key Analysis
- Overall Equipment Effectiveness (OEE)
- Machine-wise performance
- Production analysis
- Downtime analysis
- Defective and rework units
- Quality analysis

## Objective
To analyse manufacturing performance, identify production inefficiencies and understand machine downtime and quality issues using data visualization.
